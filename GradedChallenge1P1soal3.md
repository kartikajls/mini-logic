# Assignment Directions

## 3 Conditional & Looping

Write a program in Golang that prompts the user for an integer and then outputs whether that integer is even or odd. The program should also prompt the user to continue or quit. If the user chooses to continue, the program should prompt the user for another integer; otherwise, the program should terminate.

Instructions:

- The program should prompt the user to enter an integer.
 
- The program should output whether the integer is even or odd.

- The program should prompt the user to continue or quit.

- If the user chooses to continue, the program should prompt the user for another integer; otherwise, the program should terminate.

- The program should handle invalid input gracefully and prompt the user to enter a valid input.
