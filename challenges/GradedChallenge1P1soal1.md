## Assignment Directions

## 1 Conditional
Write a program in Golang that takes three integers as input and prints one of the following messages based on the conditions below:

- If all three integers are equal, print "All three are equal".
- If two integers are equal and the third is different, print "Two are equal and one is different".
- If all three integers are different, print "All three are different".
Your program should handle non-integer inputs by printing "Invalid input".
